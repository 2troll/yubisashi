
## Guías halal y mapas
- `python3 guia.py` → `dalil/` (árabe), `panduan/` (indonesio), `guide/` (inglés): 68 lugares de Halal Kansai.
- `python3 mapa.py <estación>|todas [--km 2]` → `mapas/<estación>.pdf`: A4 JA/AR/EN con QR a Google Maps, para hoteles. Si no cabe en una página, quita el lugar más lejano.
